# Placeholder

A private, camera-first app for saving small cool places you notice on the way. Rules and decisions live in `CLAUDE.md`.

## Run it

```
npm install
npm run dev      # local, on your computer
npm run build    # what Vercel runs
```

The camera only works on a secure (https) link, so test on phones with the Vercel link.
